# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a top priority for Supapulse. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Instead, please send an email directly to **adematalayhuryasar@gmail.com** with:
- A description of the vulnerability.
- Steps or a proof-of-concept to reproduce it.
- Suggested mitigation steps (if available).

We will investigate and respond promptly. Thank you for keeping the open-source community safe!
