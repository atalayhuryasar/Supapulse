# Contributing to Supapulse 🤝

Thank you for your interest in contributing to **Supapulse**! We welcome contributions from developers of all skill levels.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
- Check the [existing issues](https://github.com/atalayhuryasar/Supapulse/issues) to ensure the bug hasn't already been reported.
- Open a new issue using our **Bug Report** template.
- Include detailed steps to reproduce the issue, expected behavior, and screenshots or logs if possible.

### 2. Suggesting Features
- We love feature requests! Check existing issues to see if it's already discussed.
- Open a **Feature Request** issue explaining the problem it solves and how you envision it working.

### 3. Pull Requests (PRs)
1. **Fork** the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Make your changes** and test locally (`npm run dev` and `npm run build`).
4. **Commit with clear commit messages** following conventional commits:
   ```bash
   git commit -m "feat: add telegram notification webhook support"
   ```
5. **Push to your fork** and submit a **Pull Request**.

---

## 🧑‍💻 Development Guidelines

- **Framework:** Next.js 16 (App Router), TypeScript, TailwindCSS.
- **Code Style:** Clean, typed, and well-commented where necessary. Run `npm run build` to ensure there are no TypeScript or compilation errors.
- **Database:** Supabase PostgreSQL with strict Row Level Security (RLS) policies.

---

## 📜 Code of Conduct

By participating in this project, you agree to abide by our code of conduct: treat everyone with respect, kindness, and empathy.
